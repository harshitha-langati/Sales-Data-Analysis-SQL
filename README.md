# 🛒 Sales Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data using **MySQL**. The goal is to explore sales performance, customer behavior, product categories, and order trends by writing SQL queries.

The project uses the Brazilian E-Commerce Public Dataset by Olist to answer real-world business questions and generate meaningful insights from the data.

## 🎯 Project Objectives

- Analyze overall sales and order performance.
- Identify top-selling product categories.
- Understand customer purchasing behavior.
- Find the top customers based on spending.
- Analyze sales across different states.
- Identify monthly sales trends.
- Evaluate order delivery performance.
- Answer business questions using SQL queries.

## 📂 Dataset

**Dataset Name:** Brazilian E-Commerce Public Dataset by Olist

**Source:** Kaggle

[Download the Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The dataset contains information about:
- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

*Note: The original dataset is available through the Kaggle link above. Download it separately to run the project.*

## 🛠️ Tools & Technologies

- **MySQL** – Database management and querying
- **MySQL Workbench** – Writing and executing SQL queries
- **SQL** – Data exploration, cleaning, and analysis

## 📊 Analysis Performed

### 1. Data Exploration
- Explored the available tables.
- Checked total records in each table.
- Examined columns and data types.
- Identified relationships between tables.

### 2. Data Cleaning
- Checked for missing values.
- Identified duplicate records.
- Checked order statuses.
- Examined unusual values in sales and freight amounts.

### 3. Basic SQL Analysis
- Total number of customers.
- Total number of orders.
- Order status distribution.
- Top 10 expensive products.

### 4. Intermediate SQL Analysis
- Top 10 customers by spending.
- Sales by product category.
- Sales by customer state.
- Average order value.

### 5. Advanced SQL Analysis
- Monthly sales trends.
- Top products using ranking functions.
- Repeat customer analysis using CTEs.
- Late delivery analysis.
- Month-over-month sales growth using window functions.

## 📚 SQL Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions (SUM, COUNT, AVG)
- INNER JOIN, LEFT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER()
- RANK() and DENSE_RANK()
- LAG()

## ⚠️ Project Limitation

The dataset provides product prices and freight charges but does not provide product costs. Therefore, this project focuses on sales analysis and does not calculate actual business profit.
